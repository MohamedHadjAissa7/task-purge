# Mindful Flow

بناءً على المعلومات المستخرجة من الفيديو الذي قام فيه المبرمج ببناء تطبيق "MyMind"، إليك شرح تفصيلي وعميق لكل مكونات التطبيق، وكيفية عملها معاً لتشكيل نظام إنتاجية متكامل:

1. الفلسفة الأساسية للتطبيق

لم يكن التطبيق مجرد قائمة مهام عادية، بل بُني على أسس نفسية لكسر "التسويف" وتحفيز الدوبامين:

التقليلية (Minimalism): واجهة خالية من المشتتات، تعتمد على لون داكن مريح للعين (Dark Mode) بأسلوب Glassmorphism (تصميم زجاجي شفاف) ليعطي طابعاً مميزاً وهادئاً.

السرعة والسهولة: التخلص من الاحتكاك (Friction) عند إضافة المهام. الإدخال يتم بالكامل تقريباً عبر الكيبورد لتقليل الجهد العقلي اللازم للبدء.

التدمير الذاتي: التخلص من عبء المهام المتراكمة. إذا لم تُنجز المهمة بحلول منتصف الليل، تُحذف نهائياً. هذا يضيف ضغطاً إيجابياً للإنجاز ويمنحك بداية نظيفة كل يوم.

اللعب (Gamification): تحويل العمل إلى لعبة، حيث تحصل على "شارات" (Badges) ومؤثرات صوتية عند الإنجاز، وتتابع تقدمك عبر رسوم بيانية.

الوحدة الزمنية (الأسبوع): التركيز على أهداف أسبوعية قابلة للقياس، بدلاً من الأهداف اليومية العشوائية المشتتة.

2. واجهة التطبيق وميزاته (الويب والهاتف)

التطبيق مقسم إلى أربع شاشات أو أقسام رئيسية تتكامل مع بعضها:

أ. قسم إدارة المشاريع (Project Management)

الفكرة: هي الخطة الأسبوعية الكبيرة. في بداية كل أسبوع، يقوم المستخدم بمسح مشاريع الأسبوع الماضي وكتابة مشاريع أو أهداف هذا الأسبوع.

الآلية: يتم تقسيم أي هدف كبير إلى "مشاريع صغيرة" لتسهيل التعامل معها.

التأثير: هذا القسم يمنح المستخدم نظرة عامة (Bird's-eye view) على ما يجب إنجازه خلال الأسبوع.

ب. قسم المهام اليومية (Task Management)

الفكرة: هنا يتم تحويل "المشاريع" إلى خطوات تنفيذية ملموسة.

الإضافة السريعة: يمكن كتابة المهمة، استخدام الأسهم (Arrows) لاختيار المشروع الذي تتبعه، ثم الضغط على Enter. الواجهة تعود فوراً لتكون جاهزة لاستقبال المهمة التالية دون استخدام الماوس.

التحفيز النفسي:

حجم خانة التحديد (Checkbox) أو المهمة تم جعله كبيراً عمداً، ليشعر المستخدم بإنجاز حقيقي عند النقر عليه.

إضافة مؤثر صوتي (صوت إنجاز) عند وضع علامة "صح".

النهاية اليومية: المهام المنجزة تُرحل إلى الإحصائيات. المهام غير المنجزة تُحذف عند الساعة 12 منتصف الليل لبداية يوم جديد.

ج. قسم مؤقت التركيز (Pomodoro Timer)

الفكرة: أداة لتطبيق تقنية البومودورو (العمل لفترات محددة يتخللها فترات راحة قصيرة).

التصميم: تم تصميمه بأسلوب الساعة القلابة الكلاسيكية (Flip Clock Design) الذي أحبه المبرمج.

الوظيفة: عندما يبدأ المؤقت، يأخذ الشاشة بالكامل (Full Screen) ليمنع المستخدم من النظر لأي شيء آخر.

المرونة: يمكن للمستخدم تحديد مدة جلسة العمل أو التركيز من خلاله.

التغذية التلقائية: الساعات والدقائق التي ينجزها المستخدم في هذا المؤقت تُحفظ وتُضاف تلقائياً إلى صفحة الإحصائيات.

د. قسم الإحصائيات (Statistics & Analytics)

هذا هو القسم الذي اعتبره المبرمج "الادمان" الفعلي في التطبيق، وهو القسم المسؤول عن تتبع التقدم:

تتبع الاستمرارية (Consistency Track): يعتمد على مبدأ عدم كسر السلسلة. حتى لو تم إنجاز مهمة واحدة أو العمل لدقيقة واحدة، يعتبر اليوم ناجحاً ويتم تلوين اليوم باللون الأخضر. الهدف هو بناء عادة الاستمرارية.

شارات الأداء (Badges): تتغير الكلمات أو الألقاب (مثل: مبتدئ، محترف، إلخ) بناءً على عدد ساعات التركيز التي قضاها المستخدم من بداية الأسبوع. تُستخدم هذه الألقاب كشرط لمكافأة الذات (مثلاً: لن أشتري كذا إلا إذا حصلت على الشارة كذا).

الرسوم البيانية (Curves/Graphs): تحويل ساعات العمل والمهام المنجزة إلى رسوم بيانية صاعدة وملونة. رؤية الجهد يتحول إلى خطوط بيانية صاعدة تولد شعوراً بالرضا والتحفيز.

3. بنية النظام (Architecture & Tech Stack)

التطبيق هو نظام شامل (Full-Stack) يتكون من ثلاثة أجزاء تقنية مترابطة:

الواجهة الخلفية (Backend - ASP.NET C#):

هي "المحرك" الذي يعالج كل المنطق.

تم استخدام ASP.NET Core Web API.

تم بناء نقاط وصول (Endpoints) للتحكم في (الحسابات، المشاريع، المهام، البومودورو).

تم إنشاء DTOs (Data Transfer Objects) لنقل البيانات بين قاعدة البيانات والواجهات بأمان.

قاعدة البيانات (SQL Server):

تتكون من 5 جداول رئيسية مترابطة (Users, Projects, Tasks, Pomodoros, Completed Tasks).

تم بناؤها باستخدام نهج Database First، مما يعني أن المبرمج صمم الجداول أولاً في SQL Server ثم جعل الكود يتعرف عليها.

الواجهة الأمامية وتطبيق الهاتف (Frontend - React & React Native):

موقع الويب تم بناؤه باستخدام React.

تطبيق الهاتف (الذي يحتوي فقط على إضافة المهام والمؤقت للسرعة قبل النوم) تم بناؤه باستخدام React Native و Expo Go.

تم ربط الواجهتين بالـ Backend باستخدام مكتبة Axios."أنت مبرمج خبير في [حدد التقنية، مثل: React و Tailwind CSS]. أريدك أن تساعدني في بناء موقع ويب لـ [اكتب فكرة الموقع]. التقنيات المطلوب استخدامها: [مثل: React, ASP.NET Core API]. أسلوب التصميم: [مثل: Dark Mode, Minimalist, Glassmorphism]. الوظائف الرئيسية: [اذكر الميزات مثل: إدارة المهام، مؤقت بومودورو، إحصائيات]. أولاً، ابدأ بإعطائي هيكل المجلدات (Folder Structure) والصفحات الرئيسية التي نحتاجها دون كتابة الأكواد الكاملة بعد."

خطوات التوجيه الذكي للحصول على أفضل كود:

البناء المكوني (Component-by-Component): لا تطلب بناء الموقع كاملاً في أمر واحد لتجنب انقطاع الكود أو اختصاره.

مثال: "الآن اكتب لي كود مكون المؤقت (Timer Component) باستخدام تصميم Flip Clock، واجعله يأخذ الشاشة بالكامل عند التشغيل."

وصف تجربة المستخدم (UX Details): حدد كيف يتفاعل المستخدم مع الشاشة.

مثال: "أريد إضافة المهام بالضغط على زر Enter مباشرة بدون استخدام الماوس، واجعل الخيار يتنقل للأسفل تلقائياً."

معالجة الأخطاء فوراً: عند ظهور أي خطأ أثناء التشغيل، انسخ رسالة الخطأ كاملة واكتب له: "ظهر هذا الخطأ في Terminal عند تشغيل الكود، ما السبب وكيف نحله؟"

ربط الواجهات بالباك إند: عند الانتهاء من الواجهات، اطلب دمج الـ APIs:

مثال: "اكتب لي مكتبة Axios لربط شاشة المهام بـ API الباك إند المعمول بـ ASP.NET."1. قاعدة البيانات (SQL Server)

الهدف: بناء الهيكل الأساسي وتحديد العلاقات بين الجداول.

الموجه (Prompt):

"قم بكتابة كود SQL لإنشاء قاعدة بيانات SQL Server لتطبيق إنتاجية شخصية. أريد 5 جداول رئيسية:

Users: للبيانات الأساسية.

Projects: للمشاريع الأسبوعية.

Tasks: للمهام اليومية المرتبطة بالمشاريع، مع إضافة حقل CreatedAt لتحديد وقت الإضافة.

PomodoroSessions: لتسجيل الجلسات ومدتها بالدقائق.

CompletedTasks: لجميع المهام المكتملة لغرض الإحصائيات. قم بإضافة المفاتيح الرئيسية والفرعية (Foreign Keys) والعلاقات بين الجداول بدقة."

2. الواجهة الخلفية (ASP.NET Core Web API)

الهدف: بناء محرك النظام، معالجة البيانات، وتزويد الواجهات بالـ APIs.

الموجه (Prompt):

"أريدك مبرمج خبير في ASP.NET Core Web API و Entity Framework Core. قم بإنشاء الـ Controllers والـ DTOs التالية:

TasksController: يتضمن إضافة مهمة، جلب مهام اليوم، وتعيين المهمة كـ 'مكتملة'. أضف ميزة (Background Service أو Endpoint) لحذف المهام غير المنجزة عند الساعة 12 منتصف الليل.

PomodoroController: لتسجيل وقت جلسة التركيز المكتملة.

StatsController: لحساب إجمالي الساعات وتتبع الاستمرارية اليومية (Streak). استخدم بنية المجلدات القياسية (Controllers, Services, DTOs, Models)."

3. واجهة الويب (React & Tailwind CSS)

الهدف: بناء الواجهات الرئيسية بتصميم زجاجي مظلم (Dark Glassmorphism) وإدخال سريع بالمركبات.

الموجه (Prompt):

"أنت مبرمج React خبير في Tailwind CSS. قم بكتابة مكونات (Components) لتطبيق إنتاجية بأسلوب Dark Mode و Glassmorphism:

TaskInput: نموذج إدخال مهام يتيح لي كتابة اسم المهمة، واختيار المشروع بالأسهم، ثم الضغط على Enter للحفظ والتحويل المباشر للمهمة التالية دون مسك الماوس.

FlipClockTimer: مؤقت بومودورو بتصميم الساعة القلابة، مع إمكانية التكبير إلى وضع الشاشة الكاملة (Full Screen).

StatsDashboard: شاشة إحصائيات تستخدم مكتبة Recharts لرسم منحنيات الإنجاز الصاعدة، مع نظام ألقاب (Badges) يتغير بناءً على عدد الساعات المنجزة أسبوعياً."

4. تطبيق الهاتف (React Native & Expo)

الهدف: بناء تطبيق هاتف خفيف مخصص فقط للمهام اليومية والمؤقت السريع قبل النوم.

الموجه (Prompt):

"أنشئ تطبيق React Native مبسط باستخدام Expo لمهام الإنتاجية بتصميم مظلم مريح للعين:

الشاشة الأولى: قائمة المهام اليومية بحجم أزرار كبير، مع تشغيل مؤثر صوتي خفيف عند التحديد (Check).

الشاشة الثانية: مؤقت بومودورو مبسط. اجعل الواجهات متجاوبة، واستخدم Axios للتواصل مع APIs الواجهة الخلفية."
